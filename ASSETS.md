## Fonts (OFL 1.1)

- Barlow by Jeremy Tribby and the Barlow Project Authors. Files `assets/fonts/Barlow-*.ttf`. License text: `assets/fonts/OFL-Barlow.txt`.
- IBM Plex Mono by IBM. Files `assets/fonts/IBMPlexMono-*.ttf`. License text: `assets/fonts/OFL-IBMPlex.txt`. Reserved font name: Plex.

The interface font files were taken from the Fontsource builds of those families (latin, weights 400/500/600 for Barlow and 400/500 for IBM Plex Mono).
